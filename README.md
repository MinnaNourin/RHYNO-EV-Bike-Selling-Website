# Rhyno EV Bike Selling Website 🚲⚡  

🌐 **Live Demo:** [Rhyno EV Bike Selling Website](https://minnanourin.github.io/RHYNO-EV-Bike-Selling-Website/)  

A modern, responsive e-commerce style website for showcasing the Rhyno EV brand and its electric bikes. Developed as a frontend project demonstrating web design, UI/UX, and product-driven layout.

---

## ✨ Features

- Clean, mobile-friendly layout with a hero banner, product highlight section, and bike catalogue  
- Detailed product pages for each Rhyno bike model (features, specs, gallery)  
- Interactive UI elements: hover effects on bikes, call-to-action buttons (“Book Now”, “Learn More”)  
- About Us section explaining the brand story and mission of Rhyno EV  
- Contact / Enquiry form (frontend only) for potential leads  
- Semantic HTML5, CSS3 & JavaScript for smooth behaviour and responsive rendering  

---

## 🛠️ Tech Stack

- **HTML5** — semantic structure and accessibility  
- **CSS3** — layout, flex/grid, styling, media queries  
- **JavaScript** — basic interactivity (navigation toggles, image sliders etc.)
