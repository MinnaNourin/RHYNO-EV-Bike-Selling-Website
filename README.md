# 🚲 Rhyno EV Bike Selling Website  

🌐 **Live Demo:** https://minnanourin.github.io/RHYNO-EV-Bike-Selling-Website/  

A responsive e-commerce-style web application designed to showcase electric bikes under the Rhyno EV brand. This project demonstrates frontend development, user interface design, and structured product presentation.

---

## 📌 Project Objective

To design and develop a modern product showcase platform that simulates an online bike-selling experience, focusing on usability, responsiveness, and clear product communication.

---

## ✨ Key Features

- Fully responsive design optimized for mobile, tablet, and desktop  
- Product catalogue with dedicated pages for each bike model  
- Image galleries and structured product specifications  
- Interactive UI elements (hover effects, navigation, call-to-action buttons)  
- Smooth navigation and user-friendly layout  
- Contact/Enquiry form (frontend implementation)  

---

## 🛠️ Tech Stack

- **HTML5** — semantic structure  
- **CSS3** — responsive design using Flexbox & Grid  
- **JavaScript** — UI interactivity (navigation, sliders, dynamic behavior)
